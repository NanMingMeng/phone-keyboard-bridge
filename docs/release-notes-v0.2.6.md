# PKB v0.2.6

这个版本只有一个改进，主要目的是验证自动更新流程能正常跑通。

## 本次改进

- 更新下载失败时，询问是否打开 GitHub 发布页手动下载；确认后自动在浏览器打开对应版本的下载页面

## 说明

- 功能与 v0.2.5 相同
- 发布这个版本是为了让你能在软件里点“立即检查更新”，实测从 v0.2.5 自动升级到 v0.2.6 的完整过程：检查更新、镜像下载、断点续传、SHA256 校验、替换文件并自动重启

## 限制

- 局域网 http 页面没有系统通知权限，无法把手机浏览器强行弹到前台
- 镜像通道速度受网络影响，本次 55.7 MB 实测约 3 分钟
