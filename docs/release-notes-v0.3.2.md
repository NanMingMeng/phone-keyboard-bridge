# PKB v0.3.2

修复"一键开启系统通知"时教程被下载面板盖住的问题。

## 本次改进

- 点「一键开启系统通知」后，**先显示完整教程**，不再同时触发下载
- 教程分三步写清：① 点下载证书 ② 去设置里安装 CA 证书 ③ 回来点跳转
- 教程层里明确提示"下载面板弹出后关掉它，这个教程会一直在"
- 点「下载证书」下载完成后，教程切换成"证书已开始下载"，并给出找不到文件时的位置提示（文件管理器的「下载」目录）
- 下载按钮和跳转按钮分两步，用户不会因为下载面板挡住而漏看说明

## 使用流程

1. 手机打开普通页面，点「一键开启系统通知」→ 看到三步教程
2. 点「下载证书」→ 下载面板弹出，关掉它，教程还在
3. 按教程去设置里装 CA 证书
4. 回来点「装好了，去通知版页面」→ 打开 HTTPS 地址 → 点「开启系统通知」授权

## 其他

- 功能与 v0.3.1 相同，只修引导流程
