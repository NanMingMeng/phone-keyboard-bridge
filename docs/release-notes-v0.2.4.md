# PKB v0.2.4

这个版本解决“设备列表越积越多”的问题，并新增从电脑唤醒手机打字界面的功能。

## 本次改进

- 同一台手机换网络后不再重复要求授权：电脑会记住手机的长相（机型、浏览器、屏幕、时区、语言），换地址后自动认回原来的授权
- 设备列表不再堆积重复记录；已授权设备卡片新增“合并重复设备”按钮，一键整理历史遗留记录，操作次数会累加
- 修好重启后所有设备都显示“刚刚”的问题，现在显示真实的“上次连接时间”，从没连过则显示“从未连接”
- 新增“打开打字界面”：在电脑上点一下某台已授权设备，手机页面会自动从遮罩切回打字界面并把光标放进输入框
- 上次连接时间、操作次数现在会随记录一起保存，重启软件不丢

## 使用提示

- 唤醒功能要求手机页面还开着（切到后台也算），最多 4 秒生效
- 手机页面完全关掉时唤醒信号会保留，下次打开页面直接就是打字界面
- 合并重复设备按“浏览器型号”归组；如果两条记录各自都有不同的指纹，会被判定为两台不同手机，不会合并

## 限制

- 局域网 http 页面没有系统通知权限，无法把手机浏览器强行弹到前台
- 换网络后手机仍需重新打开一次页面，但不需要再点授权确认
- 目标软件必须支持文字/文件粘贴，这一条与之前版本相同
