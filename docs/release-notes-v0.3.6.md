# PKB v0.3.6

修复“检查更新”被安卓版发布干扰的问题。

## 之前报错的原因

仓库里同时发布安卓客户端，安卓使用了独立版本号（例如 `v0.4.0`）。GitHub 的「最新发布」是按创建时间取的，会选中安卓那一次；而安卓发布里只有 APK，没有 `PKB.exe`，桌面版就报“最新版本缺少 PKB.exe 或校验文件”。

## 本次修复

- 更新检查不再只看「最新发布」，而是拉取发布列表，挑出**最新的、真正带 PKB.exe 与校验文件**的版本
- 安卓发布的标签再大也不会干扰桌面版
- 预发布（prerelease）和草稿会被自动跳过
- 桌面版版本号仍然按 `v0.x.y` 递增

## 验证

- 当前 0.3.5：提示已是最新
- 模拟 0.3.0：正确发现 0.3.5
- 模拟 1.0.0：提示已是最新（不会倒退到更低的版本）

## 其他

- 功能与 v0.3.5 相同，只修更新检查
