# PKB v0.2.0

这个版本把 PKB 从“能用的远程输入工具”升级成可以长期后台运行的桌面工具。

## 本次新增

- 首次连接电脑弹窗确认，支持设备别名
- 手机本地保存随机设备 ID，换 IP 仍能识别同一设备
- 已授权设备可在设置页改名或撤销授权
- 扫码状态：等待扫码、已扫码等待确认、连接成功、已拒绝、已离线
- 手机端底部固定操作栏，键盘弹起后按钮仍然可见
- 选图后临时展开“粘贴图片 / 只保存图片”
- 独立发送记录页，最多保存 50 条
- 记录支持复制、单条删除、全部清空
- 删除记录时同时删除对应图片文件（删除前确认）
- 关闭窗口隐藏到系统托盘，服务继续运行
- 开机自启并弹出 PKB 主窗口
- 一键连接自检：服务、端口、IP、手机页面、防火墙、网络类型
- 连接异常时提供修复建议和防火墙设置入口
- 重置连接令牌时同时清空已授权设备
- 浅色 / 深色跟随 Windows

## 使用提醒

- 第一次连接必须由电脑端点击“允许连接”
- 关闭窗口不会退出，托盘菜单“退出 PKB”才会停止服务
- 记录和已授权设备保存在本机数据目录，不会上传云端
- 清理发送记录会删除对应图片文件，请确认后再操作
