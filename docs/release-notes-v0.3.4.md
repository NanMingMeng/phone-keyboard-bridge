# PKB v0.3.4

修复教程弹层被自动关掉的问题。

## 之前的问题

教程复用了"连接遮罩"，而手机页面每 4 秒会给电脑发一次心跳，心跳返回成功时会把遮罩关掉。所以点完按钮后教程最多显示 4 秒就消失；而下载证书、进设置安装往往要几十秒，用户回来时层已经没了，找不到"去通知版页面"按钮。

## 本次改进

- 教程改成独立的底部弹层，心跳不会影响它，只有用户自己点「稍后再说」才会关闭
- 教程里同时给出两个按钮：「下载证书」和「我已装好证书，去通知版页面」，装没装都能找到入口
- 页面顶部增加常驻入口：下载过证书后，http 页面顶部直接显示「去通知版页面」
- 下载状态记在浏览器本地，页面刷新、切到设置再回来都还记得
- 教程打开期间，连接状态的提示不会再弹出来打断

## 使用流程

1. 手机打开普通页面，点「一键开启系统通知」→ 底部弹出三步教程
2. 点「下载证书」→ 关闭下载面板，教程仍在，标题变成「第 2 步：安装证书」
3. 进手机设置装好 CA 证书
4. 回到浏览器，点「我已装好证书，去通知版页面」→ 打开 HTTPS 地址 → 点「开启系统通知」

如果中途把页面关了，重新打开时顶部会直接显示「去通知版页面」。
