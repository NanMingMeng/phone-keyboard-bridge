# PKB v0.3.1

这个版本把"开启系统通知"的步骤压缩到最少。

## 本次改进

- 普通 http 页面顶部新增「一键开启系统通知」按钮
- 点一下自动下载证书，并弹出安装说明
- 说明页里带「装好了，去通知版页面」按钮，装完直接跳到 HTTPS 地址
- HTTPS 页面顶部保留「开启系统通知」按钮，点一次授权即可

## 关于"一键安装证书"的说明

Android 系统不允许任何 App 静默安装证书，安装 CA 证书必须经过系统设置里的「安装证书」通道，这是平台的安全策略。所以流程最短只能做到：

1. 页面点一次按钮（自动下载证书）
2. 手机设置里搜索「安装证书」，选「CA 证书」，安装下载的文件
3. 回到页面点「装好了，去通知版页面」

## 如果不想装证书

可以在后续版本改用第三方推送 App（例如 ntfy），不需要证书也能收到系统通知，但需要安装一个 App 并且电脑能访问外网。这个方案还没有实现，需要单独排期。

## 其他

- 功能与 v0.3.0 相同，只优化了引导流程
