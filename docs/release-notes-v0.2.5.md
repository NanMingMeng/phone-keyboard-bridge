# PKB v0.2.5

这个版本修复“点更新后下载卡住、下载失败”的问题，并保留 v0.2.4 的全部改进。

## 本次改进

- 下载更新时自动切换通道：先试 GitHub 官方地址，速度过低或断线就自动换镜像
- 支持断点续传：中途断了不会从头再来，会接着已下载的部分继续
- 同一个通道最多重试 3 次，全部通道失败后才报错
- 下载速度低于 60 KB/s 并持续 20 秒会自动放弃当前通道，避免长时间卡住
- 下载完成后仍会做完整 SHA256 校验，文件不对就不安装

## v0.2.4 已包含的功能

- 同一台手机换网络后不再重复要求授权（按机型、浏览器、屏幕、时区、语言识别）
- 新增“合并重复设备”按钮，一键整理历史遗留记录
- 修复重启后设备全部显示“刚刚”的问题
- 新增“打开打字界面”：电脑点击已授权设备，手机页面自动切回打字界面

## 限制

- 局域网 http 页面没有系统通知权限，无法把手机浏览器强行弹到前台
- 换网络后手机仍需重新打开一次页面，但不需要再点授权确认
- 镜像通道速度受网络影响，1GB 文件更新会更慢，软件本身不受影响
