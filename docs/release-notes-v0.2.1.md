# PKB v0.2.1

这个版本加入程序内自动更新。

## 本次新增

- 设置页新增“软件更新”卡片
- 启动时每天自动检查一次 GitHub 最新版本
- 可以手动点“立即检查更新”
- 发现新版本后提示版本号和更新说明
- 下载 `PKB.exe` 后自动核对 SHA-256
- 下载完成后退出 PKB，替换旧 exe 并自动重启
- 更新失败时保留旧版本
- 自动检查可以关闭

## 重要说明

- 自动替换只对打包后的 `PKB.exe` 生效
- 从源码运行 `run_desktop.py` 时只能检查和下载，不能替换自身
- v0.2.0 本身没有更新器，需要手动换到 v0.2.1；从 v0.2.1 开始以后可以在程序内更新
- 如果 GitHub 下载失败，不会删除当前可用版本

## 验证

- GitHub Releases API 连接测试通过
