# v0.3.9

## 新增

- **手机打字页支持自动序号**。输入框下方新增「自动序号（1) 2) 3)…）」开关：

  - 开启时若输入框为空，自动填入 `1) `；
  - 回车另起一行，自动补下一个序号；在中间插入、删除某行后，所有序号按顺序重排（`NUM_RE` 只认行首的 `N) `）；
  - 粘贴到电脑或点「清空」后，输入框重置回 `1) `；
  - 开关状态与草稿内容都存在手机本地存储（`phone-keyboard-autonum` / `phone-keyboard-text`），刷新页面、切后台都不丢。

- 输入法组字中（`isComposing` / `keyCode 229`）与 `Ctrl+Enter` 不拦截，中文输入与换行发送逻辑不受影响。

## 说明

- 只改了电脑端下发的页面模板 `phone_keyboard/templates/index.html`，**手机端无需升级**，刷新页面即可看到新开关。
- 前台窗口名显示、4 秒会话心跳、设备按机型自动归并等 0.3.7 / 0.3.8 的能力保持原样。

## 升级

覆盖程序后重启桌面端（`启动PKB.cmd`），手机浏览器下拉刷新；App 内嵌页面重新打开即可。
