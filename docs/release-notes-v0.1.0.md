# PKB v0.1.0

PKB（手机键盘桥 / Phone Keyboard Bridge）是一个局域网工具：在手机上打字或选图，内容会自动粘贴到 Windows 当前窗口。

## 下载

- `PKB.exe`：Windows 10/11 单文件版，双击运行，不需要安装 Python。
- `PKB.exe.sha256`：可执行文件的 SHA-256 校验值。
- `PKB-assets-0.1.0.zip`：软件图标和四页界面截图。
- GitHub 自动生成的 Source code 压缩包：完整源码。

## 本次包含

- Windows 桌面版，开启后自动启动本机服务
- 手机扫码连接
- 手机文字自动粘贴到电脑当前输入框
- 手机选图 / 拍照后自动粘贴图片
- 粘贴后手机输入框自动清空
- 连接 / 设置 / 日志 / 关于四页
- 端口、数据目录、开机自启、连接令牌设置
- 浅色 / 深色跟随 Windows 系统
- 单文件 exe，支持 Windows 10/11

## 使用方法

1. 双击 `PKB.exe`。
2. 第一次运行如果弹出 Windows 防火墙提示，选择“允许”，否则手机无法通过局域网连接。
3. 手机和电脑连接同一个 Wi-Fi 或热点。
4. 手机扫描窗口里的二维码。
5. 先在电脑上点一下目标输入框，再在手机页面打字或选图。

## 安全说明

- 默认只建议在可信局域网内使用，不要把端口直接暴露到公网。
- 二维码地址中包含随机连接令牌，公开截图前请先确认是否要打码。
- 文字和图片不经过云端，只在本机与手机之间传输。
