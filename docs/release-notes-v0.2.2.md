# PKB v0.2.2

这个版本加入任意文件发送。

## 本次新增

- 手机端新增“发送文件”按钮
- 支持 PDF、Word、ZIP、压缩包等任意文件，单文件最大 100MB
- 文件会保存到数据目录的 `files` 文件夹
- 通过 Windows 文件剪贴板模拟 Ctrl+V
- 支持粘贴文件到微信、Codex 等接受文件粘贴的软件
- 失败时自动保留文件，并可在记录页重新复制到剪贴板
- 记录页支持文件记录、复制和删除
- 手机底部栏压缩为 5 个按钮，避免挤出屏幕

## 限制

- 只有目标软件本身支持“粘贴文件”时，才能自动放入
- 记事本、纯文本输入框等不接受文件的软件无法接收文件
- 这类情况会保存文件并返回电脑路径
