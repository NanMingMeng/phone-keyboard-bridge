# PKB v0.2.7

这个版本让“打开打字界面”这个功能真正能看见效果。

## 为什么之前像没反应

信号其实一直有送到手机（电脑端记录里能看到“电脑唤醒打字界面”的次数在增加），但手机本来就停在打字界面上，所以“切回打字界面”这个动作没有任何可见变化，看起来就像没起作用。

## 本次改进

- 手机收到呼叫时：**震动两下**、**响一声提示音**、页面顶部弹出蓝色横幅「电脑已呼叫这台手机，可以开始打字了」
- 收到呼叫时输入框边框会高亮，连接状态标签变成「已连接 · 电脑呼叫」
- 手机标签页在后台时，标题会变成「⚡ 电脑呼叫中」，切回来第一眼就能看到
- 手机从后台切回页面时立即同步一次，不用等最多 4 秒的轮询间隔
- 桌面端提示更准确：手机在线时提示“几秒内会震动并弹出提示”；手机离线时提示“信号已排队，下次打开页面自动进入”

## 需要注意

- 手机页面必须还开着（前台或后台标签页都算），关掉浏览器就收不到呼叫
- 手机锁屏、浏览器被系统冻结时，震动和提示音不会执行，切回页面后才会补上横幅
- 局域网 http 页面没有系统通知权限，无法主动点亮屏幕或把浏览器弹到最前

## 其他

- 功能与 v0.2.6 相同，只增强了呼叫提示
