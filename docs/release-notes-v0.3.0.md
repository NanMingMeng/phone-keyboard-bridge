# PKB v0.3.0

这个版本加上了**手机系统通知**：你切出去用别的软件时，电脑点一下按钮，手机会在通知栏弹出消息、响铃、震动。

## 为什么之前做不到

浏览器有硬性规定：只有 HTTPS 页面才允许调用手机的系统通知。之前用的是 http 地址，任何浏览器都会拒绝。这个版本给 PKB 加了自签 HTTPS 服务。

## 本次改进

- 新增 HTTPS 服务，端口自动使用「HTTP 端口 + 1」（默认 3005）
- 首次启动自动生成一套证书：一个本地证书颁发机构（CA）+ 一个服务器证书，有效期 10 年
- 手机可以用 `http://电脑IP:3004/pkb-ca.crt` 直接下载 CA 证书
- 页面顶部新增「开启系统通知」按钮，点一次授权后永久生效
- 电脑端二维码旁边显示 HTTPS 地址和装证书的三步说明
- 手机收到呼叫时：系统通知栏消息 + 响铃 + 震动 + 页面蓝色横幅

## 使用步骤（一次性）

1. 手机浏览器打开 `http://电脑IP:3004/pkb-ca.crt`，下载证书
2. 手机「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」里装上
3. 手机打开页面显示的 HTTPS 地址（`https://电脑IP:3005/?t=...`）
4. 页面顶部点一次「开启系统通知」，允许通知

装完证书后，以后不用重复操作；换网络导致电脑 IP 变了，证书会用同一个 CA 自动重签，手机也不需要重装。

## 需要注意

- HTTPS 是另一个地址，手机端会当成新站点，所以**第一次需要重新允许一次连接**
- 手机浏览器完全关闭、或系统把浏览器冻结时，通知发不出去；切回页面会自动补上
- 部分国产浏览器不支持系统通知，建议用 Chrome 打开 HTTPS 地址
- 局域网 http 页面仍然保留，原有的使用方式不受影响
