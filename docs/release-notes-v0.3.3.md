# PKB v0.3.3

这个版本给 root 用户提供"一键装证书"，并在 README 里补上署名声明。

## root 用户：跳过手动安装

手机已经 root（Magisk / KernelSU）的话，不用再进设置点安装证书：

1. 手机直接访问 `http://电脑IP:3004/pkb-ca-system` 下载系统证书文件（文件名形如 `d109f44c.0`）
2. 或者电脑上运行 `scripts\install-system-cert.ps1`，它会用 adb 自动完成：获取 root → 重挂载系统分区 → 推送证书到 `/system/etc/security/cacerts/` → 设置权限
3. 重启手机，系统证书生效

系统证书的好处是所有浏览器和 App 都信任，Chrome 直接打开 HTTPS 地址不会再提示证书问题。

注意：改动系统分区后，系统 OTA 更新可能失败。要撤销就删掉那个文件再重启。

## 普通用户不变

仍然是三步：点「一键开启系统通知」看教程 → 点「下载证书」→ 设置里装 CA 证书 → 回到页面点跳转。
